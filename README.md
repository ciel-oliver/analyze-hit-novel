# 爆款小说拆解 skill

把一本小说拆成可验证的叙事系统，而不是写一篇泛泛的读后感。

`analyze-hit-novel` 面向商业小说和网络小说，阅读全文后分析人物、关系、冲突、叙事顺序与节奏，并提炼作品真正有效的爆款机制。

## 核心能力

- **六维拆书**：人物设定、人物关系、冲突矩阵、故事时间线、成品叙事顺序、题材与亮点。
- **双时间线**：对照“事情真实发生的顺序”和“作者实际写出的顺序”。
- **三维节奏**：分别分析剧情强度、读者情绪和描写密度。
- **人物关系图**：使用有方向的动作标注关系，并导出 PNG；人物过多时自动拆图。
- **爆款机制**：从文本设计、读者心理和追读动力三个层面解释作品为什么有效。
- **证据与边界**：关键结论附章节依据；缺章、污染和不确定信息会明确标注，不补写原作。

## 工作流

```mermaid
flowchart LR
    A[输入小说] --> B[结构审计]
    B --> C[逐章事实卡]
    C --> D[六维拆书]
    D --> E[双时间线与三维节奏]
    E --> F[人物关系图]
    F --> G[爆款机制报告]
    G --> H[证据与一致性复核]
```

## 使用方式

将小说全文、章节或梗概交给 Codex，然后调用：

```text
$analyze-hit-novel 分析这部小说
```

支持 TXT、Markdown 以及其他可读取的长文本。全文输入会执行完整拆解；部分章节或梗概只输出限定范围内的暂定分析。

## 安装

克隆仓库后，将 `skill/analyze-hit-novel` 复制到你的 Codex Skills 目录：

```powershell
git clone https://github.com/<你的用户名>/analyze-hit-novel.git
Copy-Item -Recurse -Force ".\analyze-hit-novel\skill\analyze-hit-novel" "$env:CODEX_HOME\skills\analyze-hit-novel"
```

重新打开 Codex 会话后即可使用 `$analyze-hit-novel`。

## 方法原则

1. 先提取事实，再解释机制。
2. 不用前三章代替全书分析。
3. 不把推断写成原文事实。
4. 提炼创作规律，不复制原作情节和专有设定。
