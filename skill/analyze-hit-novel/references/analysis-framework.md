## 1. 章节卡

每章提取以下字段：

| 字段 | 说明 |
|---|---|
| 章节 | 章节号或临时编号 |
| 本章一句话 | 谁为了什么，遭遇什么，结果如何 |
| 场景与时间 | 地点、时段、相对时间位置 |
| 参与人物 | 出场并产生作用的人物 |
| 目标—阻碍—结果 | 本章最小戏剧单元 |
| 状态变化 | 人物、关系、资源、危险或认知发生了什么改变 |
| 新增信息 | 本章向读者公开的事实 |
| 隐藏信息 | 文本暗示存在但尚未解释的信息 |
| 剧情强度 | 1–5 |
| 情绪 | 类型 + 强度 1–5 |
| 描写密度 | 1 压缩 / 2 常规 / 3 场景化重点描写 |
| 章首钩子 | 开篇提出的问题、危险、反常或承诺 |
| 章末钩子 | 未完成动作、新问题、反转、决定或威胁 |
| 证据 | 章节、场景或短关键词 |

## 2. 六维总表

### 2.1 人物设定

| 字段 | 说明 |
|---|---|
| 姓名/别名 | 统一角色称呼，记录化名和称谓 |
| 年龄、性别、身份 | 明确事实；未知不猜测 |
| 表层关键词 | 初见标签、社会形象、行为风格 |
| 核心欲望 | 人物主动追求什么 |
| 核心恐惧 | 人物最怕失去或面对什么 |
| 致命缺陷/错误信念 | 导致反复错误选择的内在机制 |
| 能力与资源 | 可调用的技能、身份、财富、关系、信息 |
| 秘密 | 对他人或读者隐藏的事实 |
| 人物弧光 | 起点信念 → 关键考验 → 终点状态 |
| 剧情重量 | 主角 / 核心 / 重要配角 / 功能配角 |
| 功能类型 | 推动剧情 / 强化主角 / 双重功能 |
| 反派同理点 | 反派为何认为自己合理，读者可理解但未必认同之处 |

### 2.2 人物关系图谱

关系必须是有方向的“主语 + 动词 + 宾语”。同一对人物可以存在多条关系，并区分表层与真实层。

推荐动词：保护、控制、利用、依赖、讨好、试探、嫉妒、崇拜、隐瞒、监视、替代、背叛、赎罪、竞争、误解、拯救。

关系表字段：人物 A、动作动词、人物 B、表层关系、真实关系、关系资源、当前张力、转折章节。

### 2.3 冲突矩阵

至少检查：

- 利益冲突：双方争夺同一稀缺资源、位置或结果。
- 信念冲突：双方对“什么是正确的”有不可兼容的答案。
- 情感冲突：爱、恨、亏欠、嫉妒、依赖阻碍理性目标。
- 身份/秘密冲突：真实身份或隐瞒事实一旦曝光就改变关系。
- 方法冲突：目标相似，但可接受的手段不同。

同时与主角存在高强度利益冲突和信念冲突、且具备持续行动能力的人，通常是终局型对手；这是一条诊断线索，不是机械定律。

### 2.4 故事时间线

按故事世界的真实先后顺序记录：事件、时间、参与人物、原因、结果、首次被读者得知的章节、信息掌握者。

### 2.5 成品叙事顺序

按作者实际写出的顺序记录：章节、叙述时间点、核心事件、披露信息、隐藏信息、所用手法、章末钩子、与真实时间线的偏移。

### 2.6 题材、体量与亮点

记录：主类型、辅类型、核心受众、总字数、章节数、平均章长、核心阅读承诺，以及最扎人的三个亮点。

“核心阅读承诺”回答：读者持续阅读，期待稳定获得什么体验？例如破案推理、身份升级、情感拉扯、复仇兑现、世界探索。

## 3. 双时间线

对每项时间顺序调整使用以下标签：

| 标签 | 作用 |
|---|---|
| 提前 | 先展示后果或异常，立刻建立问题 |
| 延后 | 暂扣原因、身份或动机，形成悬念或反转 |
| 拆散 | 把同一事件分成多次披露，持续修正理解 |
| 重复 | 从不同视角或新增信息重看同一事件 |
| 省略 | 跳过低价值过程，加快节奏 |
| 并行 | 交叉剪辑两条线，制造对照、倒计时或会合期待 |

每次调整都回答三个问题：

1. 如果按真实时间顺写，会损失什么？
2. 当前顺序让读者比谁多知道或少知道什么？
3. 信息释放后，读者对人物、事件或风险的判断如何改变？

## 4. 节奏评分

### 剧情强度 1–5

| 分数 | 锚点 |
|---|---|
| 1 | 日常衔接、移动、轻微信息，无明显状态变化 |
| 2 | 小障碍、小线索、小摩擦，局部状态改变 |
| 3 | 明确进展、告白、失败、联盟变化或重要发现 |
| 4 | 重大损失、关系破裂、身份暴露、计划逆转 |
| 5 | 核心真相、不可逆抉择、高潮对决、终局性改变 |

### 情绪强度 1–5

先标类型：好奇、紧张、恐惧、兴奋、甜蜜、悲伤、愤怒、震惊、释然、厌恶、感动。再按身体唤醒程度、共情深度和余韵打分。

剧情强度与情绪强度可能分离。例如一次安静告别，外部事件只有 2 分，情绪可能达到 5 分。

### 描写密度 1–3

| 分数 | 锚点 |
|---|---|
| 1 | 概述、跳时、结果性叙述、一笔带过 |
| 2 | 常规场景，有必要动作和对话 |
| 3 | 细节、心理、环境、动作和对话被充分展开 |

诊断重点：高峰前是否有低谷或蓄力；连续高强度是否造成麻木；低强度章节是否仍承担信息、人物或余波功能；重点篇幅是否给了真正重要的节点。

## 5. 人物功能

### 推动剧情型

判断问题：如果删除这个人物，关键事件是否不会发生，或故事无法进入下一阶段？

典型角色：对手、导师、盟友、委托人、线索携带者、规则制定者、救援者、背叛者。

### 强化主角型

判断问题：该人物的主要价值是否在于让读者看到主角的性格、软肋、价值选择或变化？

典型作用：拌嘴显露脾气、弱者引出善意、旧识暴露过去、镜像角色显示另一种可能。

### 双重功能型

同一人物可能前期用于显露主角，后期成为关键推动者；也可能表面是装饰角色，实际是伏笔暗桩。分析其功能转换发生在哪一章，以及前文是否提供了公平线索。

## 6. 爆款亮点

每个亮点使用“机制链”：

> 文本设计 → 读者认知或情绪变化 → 持续阅读动力 → 可迁移原则

候选维度：高概念承诺、人物欲望、关系张力、对手压力、升级反馈、秘密与信息差、反转公平性、高潮兑现、情绪补偿、主题立意、语言辨识度。

三个亮点应尽量来自不同层次，不要都写成“反转”。

## 7. 原创迁移

按以下四层抽象：

1. 表层元素：时代、职业、场景、具体事件。
2. 戏剧机制：背叛、误认、倒计时、身份错位、资源争夺等。
3. 人物引擎：核心欲望、恐惧、错误信念与极端选择。
4. 主题张力：爱与控制、忠诚与自我、正义与代价等价值冲突。

允许迁移第 2–4 层的抽象规律，不照搬第 1 层组合和原作独有事件链。

每个新故事种子至少包含：一句话概念、主角、欲望、缺陷、对手、核心关系、第一钩子、中点反转、终局抉择、差异化说明。

## 8. 证据与置信度

为关键结论标记：

- A 明确：文本直接说明或反复证实。
- B 强推断：多处行为和结果一致支持。
- C 暂定：依据有限，存在其他解释。

证据优先写章节与场景摘要。只在必要时使用极短原文关键词，避免长段复制。
